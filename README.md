# tallyraft

Tally CSV/TSV raft tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/tallyraft/

## Install / run

```bash
git clone https://github.com/theworker02/tallyraft.git
cd tallyraft
node src/cli.js
node --test
```
